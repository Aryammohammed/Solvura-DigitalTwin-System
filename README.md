# 🌴 Solvura – Artificial Palm Digital Twin System  
### **AI‑Enhanced Smart City Operations | 2025–2026**

**Solvura** is a full Digital Twin ecosystem integrating IoT sensing, AI‑driven analytics, 3D visualization, and real‑time cloud synchronization to support sustainable smart‑city operations.  
The system links **smart artificial palm trees** with a **virtual 3D replica** of a city sector, enabling continuous monitoring of environmental conditions, energy usage, and urban stress indicators.

---

## 📌 Overview
**Solvura** creates a real‑time digital replica of a physical environment using data collected from solar‑powered artificial palm trees equipped with environmental sensors.  
Through AI‑based analysis and interactive 3D visualization, the system provides predictive insights that help optimize energy consumption, improve air quality, and support sustainable city planning.

---

## ⚠️ Problem Statement
Modern cities face challenges such as:
- Rising **energy consumption**  
- Increasing **air pollution levels**  
- Limited **real‑time environmental visibility**  
- Slow response to **environmental stress events**

Traditional monitoring systems lack integration between physical sensing, predictive analytics, and interactive visualization.

---

## 🌿 Solution
**Solvura** integrates:
- Smart artificial palm trees powered by solar energy  
- IoT sensors for environmental monitoring  
- AI models for predictive analysis  
- 3D Digital Twin visualization  
- Cloud database for instant synchronization  

This creates a unified platform for sustainable city operations.

---

## 🧠 Core Features
- **Real‑time environmental sensing**  
- **AI‑powered predictions** (Random Forest Regressor)  
- **3D Digital Twin visualization** (Unity + Three.js + R3F)  
- **Instant cloud synchronization** (Firebase)  
- **Energy analytics**  
- **Responsive React.js dashboard**  
- **Automated reporting** (Chart.js + XLSX)

---

## 🏗️ System Architecture

### **1. Physical Layer – Smart Artificial Palm Tree**
- Solar panel unit  
- BME280  
- MQ‑135  
- LDR  
- Raspberry Pi 3  
- MCP3008 ADC  

### **2. Data Acquisition Layer**
- Python scripts for sensor telemetry  
- Real‑time JSON streaming  

### **3. Cloud Layer**
- Firebase Realtime Database  
- Event‑driven synchronization  

### **4. AI Layer**
- Random Forest Regressor  
- Predictive modeling for air quality, energy usage, and stress events  

### **5. Visualization Layer**
- Unity (simulation backend)  
- Blender (Low Poly 3D modeling)  
- Three.js + R3F (WebGL rendering)  
- React.js dashboard
